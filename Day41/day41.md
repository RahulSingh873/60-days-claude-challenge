# Day 41 – Interactive Learning Studio: OOP in JavaScript

## Objective

Build an interactive learning application that teaches Object-Oriented Programming in JavaScript through visual explanations, quizzes, and hands-on coding challenges.

---

## Skills Practiced

- JavaScript prototype chain
- Constructor functions
- ES6 classes
- Inheritance
- Polymorphism
- Mixins
- Private class fields
- Composition
- Method overriding
- Object-oriented design patterns

---

## Key Learnings

- Understood how JavaScript resolves properties through the prototype chain.
- Learned the difference between `__proto__` and `.prototype`.
- Practiced building reusable objects with constructor functions and prototype methods.
- Explored ES6 classes, inheritance, and the `extends` and `super` keywords.
- Implemented encapsulation using private class fields.
- Used mixins to share functionality without deep inheritance.
- Applied polymorphism by overriding methods in subclasses.
- Reinforced OOP concepts by completing quizzes and a practical coding challenge.
