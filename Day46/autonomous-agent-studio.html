07 Agent Roster & Responsibilities

PlannerReads the buggy code and bug report once, forms a root-cause hypothesis and a fix strategy that seeds the first draft.
ExecutorWrites the first working patch implementing the Planner's strategy.
Safety MonitorScreens each draft for destructive, unsafe, or out-of-scope changes before it's scored — runs every round.
EvaluatorScores the current draft 0–100 on whether it resolves the reported bug, and issues a verdict: RESOLVED / PARTIAL / UNRESOLVED. This is the gate the stop-check reads.
CriticGiven the Evaluator's verdict, finds concrete remaining defects, edge cases, or regressions — feeds the Improver.
ImproverRewrites the draft using the prior evaluation + critique. Its output becomes next round's draft, closing the loop back to Evaluator.
Memory ManagerCondenses each round into a running memory log threaded into every subsequent Evaluator/Improver prompt, so context never resets.
Final ReviewerFires once a stop condition is met; independently signs off on the final patch or flags residual risk.
