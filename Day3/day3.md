# Day 3 - Role-Based Prompting

## What is Role-Based Prompting?

Role-Based Prompting is a technique where you assign a specific role to the AI before asking a question.The output is different for different roles as generated by their personas.

Example:

"You are a startup founder..."

or

"You are a senior software developer..."

This helps the AI respond from the perspective of that role.

## Why It Matters

AI tools like Claude produce more focused and useful responses when they understand the perspective they should use.
quality input=quality output

## Prompt Without Role

How can I build a learning app?

## Prompt With Founder Role
You are a successful EdTech founder who has built and scaled multiple learning apps to over 1 million users.
I want to build a learning app for students and professionals to learn AI, coding, and digital skills.

## Prompt With Developer Role
You are a senior full-stack developer and software architect with 10+ years of experience building scalable EdTech platforms.
I want to build a learning app where users can watch courses, complete quizzes, track progress, earn certificates, and interact with AI tutors.
Explain the architecture in a beginner-friendly way and include code structure recommendations.

## Benefits of Role-Based Prompting

1. More detailed responses
2. Better domain expertise
3. More actionable recommendations

## Key Learnings

- Giving AI a role improves response quality.
- Different roles produce different perspectives.
- Better prompts lead to better results.

// backend/services/ai-tutor/index.js
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

export async function askTutor(req, res) {
  const { question, lessonContext, studentLevel } = req.body;

  // Set headers for streaming
  res.setHeader("Content-Type", "text/event-stream");

  const stream = await client.messages.stream({
    model: "claude-sonnet-4-5",
    max_tokens: 1024,
    system: `You are a patient, encouraging tutor teaching ${studentLevel}-level students.
             Current lesson context: ${lessonContext}
             Keep answers concise. Use simple analogies. Always end with a check-in question.`,
    messages: [{ role: "user", content: question }],
  });

  // Stream tokens directly to the browser
  for await (const chunk of stream) {
    if (chunk.type === "content_block_delta") {
      res.write(`data: ${chunk.delta.text}\n\n`);
    }
  }
  res.end();
}
