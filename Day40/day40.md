## Key Learnings

- Learned how structured interview questions can generate highly customized AI assistants.
- Understood the importance of a well-defined system prompt in controlling assistant behavior.
- Explored how AI applications can separate frontend interfaces from backend AI logic.
- Learned the difference between running Claude Artifacts and using the Anthropic API with an API key.
- Gained experience designing reusable AI assistants for real-world use cases.
