  A: What is a REST API?

A REST API is a way for two applications to communicate over HTTP.

For example:

Frontend

↓

HTTP Request

↓

Backend API

↓

Database

↓

JSON Response

↓

Frontend Updates UI

The frontend doesn't access the database directly. It communicates with the backend through API endpoints.

2. HTTP Methods

The four methods you should know are:

Method	Purpose	Example
GET	Retrieve data	Fetch user profile
POST	Create data	Register a new user
PUT/PATCH	Update data	Update learning progress
DELETE	Remove data	Delete a quiz attempt

An interviewer may ask:

"When would you use POST instead of PUT?"

A good answer:

POST creates a new resource.
PUT replaces an existing resource (or creates it if supported).
PATCH updates part of an existing resource.
3. API Endpoints

Examples:

POST   /login

GET    /courses

POST   /quiz

PUT    /progress

DELETE /badge/5

Each endpoint performs one specific task.
