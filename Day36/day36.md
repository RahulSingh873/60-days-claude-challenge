# Day 36 – Cognitive Pattern Explorer

## Project Overview

Built an interactive Cognitive Pattern Explorer using Claude that guides users through three reflective chapters to explore thinking styles, decision-making patterns, and personal cognitive tendencies. The application generates a personalized Reflection Journal based on user interactions.

## Features

- Two experience modes (Calm Mode and Focus Mode)
- Three interactive reflection chapters
- Everyday decision-making scenarios
- Drag-and-drop thinking activities
- Thinking sequence arrangement exercise
- Personalized Reflection Journal
- Cognitive Pattern Breakdown visualization
- Reflection insights based on user responses
- Replay mode for comparing thinking patterns

## Key Learnings

- Learned how interactive experiences can be created using a single HTML file.
- Understood how user interactions can be translated into personalized insights.
- Explored designing reflection-based applications with smooth user experience.
- Improved understanding of UI flow, state management, and dynamic result generation.
- Learned the importance of presenting analytics in a simple and engaging format.
