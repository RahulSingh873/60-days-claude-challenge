# Day 37 – Task Compass

## Project Overview

Built an interactive Task Compass application using Claude to simulate workplace decision-making and team collaboration. The application guides users through ownership identification, task routing, and collaboration scenarios before generating a personalized Organizational Thinking Dashboard.

## Features

- Multiple workplace environment selection
- Three interactive workplace simulation stages
- Ownership identification exercises
- Task routing decision scenarios
- Collaboration challenge activities
- Personalized Organizational Thinking Dashboard
- Visual performance breakdown across key workplace skills
- Actionable insights based on user decisions
- Replay mode for comparing different workplace contexts

## Key Learnings

- Learned how workplace workflows can be modeled through interactive simulations.
- Improved understanding of task ownership, delegation, and cross-functional collaboration.
- Explored how user choices can generate personalized analytical dashboards.
- Gained experience designing decision-based interfaces using HTML, CSS, and JavaScript.
- Understood the importance of balancing ownership, collaboration, and workflow thinking in organizational environments.
