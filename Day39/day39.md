# Day 39 – PDF Splitter & Merger

## Objective
Build a browser-based PDF Splitter & Merger using Claude that allows users to split PDFs by custom page ranges, page count, or selected pages, and merge multiple PDF files into a single document while processing everything locally for privacy.

## Key Learnings
- Learned how to build a complete client-side PDF processing application using HTML, CSS, and JavaScript.
- Understood different PDF splitting methods including custom page ranges, fixed page intervals, and selected page extraction.
- Explored drag-and-drop file uploads, page previews, and interactive document management.
- Implemented PDF merging with file reordering while maintaining document sequence.
- Reinforced the importance of local browser processing for improved privacy and security without uploading files to external servers.
- Improved UI/UX design skills by creating an intuitive workflow for document processing.
