## Key Learnings

- Apply to **Zaalima** and **Sachram** first — freshest postings, best skill match
- **React.js** is the critical gap — a single React project on GitHub changes everything
- Stipends range ₹1k–10k/month; **OrbitXII** and **Sachram** offer the best compensation
- Most top product companies (Razorpay, Adobe, CRED) don't post on Indeed — apply via their **official career pages**
- A deployed project with a proper README beats raw code every time
- Get referrals from seniors — they dramatically improve shortlisting odds
