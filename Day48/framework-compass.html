How this was researched
Methodology & source conflicts ▶

Job market demand is drawn from the Stack Overflow Developer Survey 2025 "Popularity" metric (share of ~49,000 professional developers who used each framework in the past year): React 44.7%, Angular 18.2%, Vue.js 17.6%, Svelte 7.2%. This is the most direct public proxy for how often each framework appears in real job requirements, though it measures current usage rather than open job postings directly.

Learning curve has no single authoritative benchmark — no survey directly measures "time to competence." Instead this score is a qualitative composite built from consistent consensus across seven independent comparison articles and guides (Academind, InfoWorld, UXPin, Zero To Mastery, Emvigo, Teqnovos, and a Medium framework comparison), all of which independently rank Vue as easiest, React as moderate, Angular as steepest, with Svelte generally described as simple syntax but a younger/thinner set of learning resources. ⚠ Composite estimate — not a single cited statistic

Performance uses production bundle-size figures for a comparable "typical to-do app" build, reported by DiNeuron's 2025 framework guide: Svelte ~10KB, Vue ~30KB, React ~42KB, Angular ~130KB. This was cross-checked against a second bundle-size source (Medium/SvelteKit comparison citing GeeksforGeeks, 2025) and the community-run js-framework-benchmark project, both of which agree on the same ranking order (Svelte < Vue < React < Angular) even though exact KB figures vary by app complexity and build configuration.

Long-term career growth uses the Stack Overflow 2025 "Desired" metric — the share of developers who want to work with each framework next year, a forward-looking signal distinct from current usage: React 30.7%, Vue.js 15.3%, Angular 12.6%, Svelte 11.1%. This is supplemented by Svelte's usage trend across three consecutive SO surveys (2.75% in 2021 → 6.5% in 2024 → 7.2% in 2025), the steepest growth curve of the four, which is reflected as a modest upward adjustment to Svelte's score.

⚠️
Conflict noted: "Admired"/satisfaction scores (Svelte 62.4%, React 52.1%, Vue 50.9%, Angular 44.7% per SO 2025) were considered as a stand-in for learning curve but were rejected for that purpose — satisfaction reflects experienced developers' preference, not a beginner's onboarding difficulty. It was used only as supporting, not primary, evidence.
