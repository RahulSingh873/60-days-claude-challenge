What is this?

The Personal AI Playbook is a self-contained tool for turning your one-off AI prompts into reusable systems, so you stop rewriting the same instructions every time you open Claude or ChatGPT.

  • Dashboard — overview of your saved workflows and quick stats.
  • Workflows — editable prompt templates organized into Daily Builds, Job Search & Applications, and Content & Brand.
  • Prompt Builder — assemble a new prompt from building blocks (role, objective, context, constraints, reasoning strategy, output format, tone, examples, quality checks), with a live text preview.
  • Loop Builder — convert a normal prompt into an autonomous looping prompt: define a goal, how to evaluate progress, how to improve each pass, when to stop, and safety rails.
  • My Library — everything you've created, favorited, or saved, searchable and filterable.

Everything is stored locally in this browser (no account, no server). Use Export to back up your library as a JSON file.

What this tool is for

Reusable AI workflow systems, not one-off prompts. Build a template once, fill in variables each time, and turn any prompt into a self-checking loop when the task needs multiple passes.

  • Workflows — editable templates grouped for daily builds, job search, and content/brand work.
  • Prompt Builder — assemble prompts from labeled building blocks with a live preview.
  • Loop Builder — add goals, evaluation criteria, and stop conditions so a prompt can iterate on itself.
